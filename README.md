# Casino Night Photo Booth

A photo booth website for a school festival casino. Open it on a phone, take one photo, pick a casino background and frame, and save.

Everything runs on the phone: photos are never uploaded. The person cut-out uses Google MediaPipe (Apache-2.0); its runtime and models are in `mp/`.
